# G6.9 Technology Selection

Technology selection follows system boundaries, not language preference.

## Control Plane

TypeScript + Node LTS + NestJS

Responsibilities:
- platform APIs
- orchestration
- business workflows

## Edge/Data Plane

Go

Responsibilities:
- long running runtime
- protocol integration
- telemetry collection

## Optimization

Python

Responsibilities:
- forecasting
- simulation
- optimization models

## Data

PostgreSQL as core database.
Time-series capability evolves with workload requirements.
