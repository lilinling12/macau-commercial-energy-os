# Engineering Authority

This directory defines engineering governance for Macau Commercial Energy OS.

Principles:

- Authority before implementation
- Contract before integration
- Validation before release
- AI assistance under engineering governance

Flow:

Research -> Decision -> Architecture -> Task -> Implementation -> Validation
