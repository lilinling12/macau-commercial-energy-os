# Productization Authority

This layer connects research and architecture with commercial execution.

Flow:

Research

-> Evidence

-> Architecture

-> Product Thesis

-> Pilot

-> MVP

Productization does not replace technical authority; it derives from it.

## Integrated dispatch workflow prototypes

- [v3.0 Traditional Chinese workflow](prototype/source-load-dispatch/v3.0/index.html)
- [v3.0 browser and interaction review](prototype/source-load-dispatch/v3.0/REVIEW.md)
- [v3.1 provisional Traditional Chinese / Portuguese / English workflow](prototype/source-load-dispatch/v3.1/index.html)

Both prototypes connect evidence qualification, physical site modeling, scenario comparison, claim/economic boundaries, SHADOW review, and replay prerequisites. They use the same fixed synthetic schedule and are not production product approval, site evidence, bill calculations or device control. v3.1 tests candidate interface copy across three locales; language scope and translations remain unapproved and need local language and user review.
