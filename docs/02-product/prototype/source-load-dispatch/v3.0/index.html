物理邊界

能源平衡、電表位置、設備連接、充放電方向與負荷服務需要現場拓撲和設備資料。這個示意沒有驗證現場平衡或可操作性。

結算邊界

帳戶、合同、費率版本、需量窗口、PV 外送權利與收款方需獨立核實。物理上有能量流，不等於帳單上可抵扣或有收入。
