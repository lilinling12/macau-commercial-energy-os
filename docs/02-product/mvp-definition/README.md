# MVP Definition

## Purpose

Define the first implementation boundary after Research, Architecture and Product Authority.

## MVP Principle

The MVP validates the Energy Intelligence loop, not full autonomous control.

Research -> Data -> Energy Model -> Tariff -> Analysis -> Recommendation -> Evidence

## Included

- Energy visibility
- Telemetry foundation
- Tariff intelligence
- Cost analysis
- Optimization shadow mode
- Savings evidence

## Not Included

- Autonomous safety-critical control
- Unvalidated AI decisions
- Full device orchestration

## First Vertical Slice

Telemetry event -> Energy Graph -> Tariff Resolution -> Cost Calculation -> Recommendation -> Evidence Record
