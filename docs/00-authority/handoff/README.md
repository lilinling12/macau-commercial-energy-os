# Macau Commercial Energy OS Handoff

This directory is the first entry point for humans and AI agents. Use repository-root paths exactly as written.

## Start sequence

1. `docs/00-authority/handoff/CURRENT.md` — current status, active PR, gates, and next work.
2. `docs/00-authority/handoff/CONTINUE-PROMPT.md` — concise instructions for resuming in a new conversation.
3. `docs/00-authority/handoff/CONTINUATION-PROTOCOL.md` — full research and AI-coding continuity workflow.
4. `docs/00-authority/handoff/HISTORY.md` — append-only material handoff changes.
5. `docs/00-authority/decisions/DECISIONS.md` and `OPEN-QUESTIONS.md` — approved decisions and unresolved questions.
6. Read the Gate, evidence, product, architecture, and task-packet records referenced by CURRENT or the active task. Research evidence and Gates live under `docs/01-research/`; task-packet templates live under `docs/04-engineering/ai-coding-governance/`.

## Authority flow

Research → Evidence → Decision → Product / Architecture → Engineering → Implementation → Validation → Handoff

Conversation history is context, not project authority. Check the live branch, pull request, exact files, and Gate state before resuming work.
