## Authority First

Before any change:

1. Read CURRENT.md.
2. Read related authority documents.
3. Check related ADRs.
4. Define validation evidence.

## Engineering Rules

- Do not silently change architecture.
- Do not bypass domain boundaries.
- Do not break contracts without versioning.
- AI generated code follows the same review and validation rules as human code.

## Workflow

Research -> Decision -> Architecture -> Engineering -> Implementation
